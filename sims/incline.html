What you are seeing

On a ramp, gravity pulls the block straight down. It is easiest to understand if you split the weight into two parts: one along the slope, which tries to make the block slide, and one perpendicular to the slope, which presses the block into the surface. The surface pushes back with the normal force, and friction acts along the surface, opposing any sliding.

Friction has two modes. While the block is at rest, static friction adjusts itself to match the push along the slope, up to a maximum of μsN. Once the block slips, kinetic friction takes over with a fixed size μkN, which is usually a little smaller.

Key formulas

Weight along slope = m g sinθ
Normal force N = m g cosθ
Static friction limit = μs N
Kinetic friction = μk N
Sliding down: a = g (sinθ - μk cosθ)
Block starts to slip when tanθ > μs

Notice that the mass cancels in the acceleration formula. A heavy and a light block with the same surface slide down a ramp identically.

Try this

  1. Set the push to 0 and slowly raise the ramp angle. At which angle does the block start to slide? Compare it with the angle whose tangent equals μs.
  2. Change the mass while the block is sliding. Does the acceleration change?
  3. Set μs = μk = 0 for a frictionless ramp. What acceleration do you get at 30°?
  4. Find the push that holds the block still at 40° with low friction.
  5. At 0°, how big a push is needed to start the block moving?

Common mistakes

  • Writing N = mg. The normal force equals mg cosθ on a slope, not mg.
  • Using μN for friction when the block is at rest. Static friction can be anything from zero up to μsN.
  • Mixing up sine and cosine. The component along the slope uses sinθ, the perpendicular one uses cosθ.

Check yourself

1. A block sits on a ramp with μs = 0.6. What is the steepest angle at which it stays at rest?

θ = tan-1(0.6) ≈ 31°.

2. What is the acceleration of a block on a frictionless 30° ramp?

a = g sin 30° = 9.81 × 0.5 ≈ 4.9 m/s² down the slope.

3. Why is it harder to start a heavy box moving than to keep it moving?

Because the maximum static friction (μsN) is generally larger than kinetic friction (μkN).
